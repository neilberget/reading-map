# reading-map

A Claude Code skill for building interactive reading-companion maps: a local MapLibre map beside a chapter-by-chapter panel of linked concepts, places, quotes and landmarks, with the book's journey traced on real lakes and rivers. The reference build is *The Lonely Land* (Sigurd F. Olson).

Install by cloning into your skills folder:

```bash
git clone https://github.com/neilberget/reading-map.git ~/.claude/skills/reading-map
```

Then ask Claude Code to "make a reading map for <book>". `SKILL.md` covers the workflow, `references/` the content and route-tracing details, and `template/` is the app that each new book starts from.
